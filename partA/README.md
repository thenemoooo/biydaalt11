# А хэсэг: API дизайн

## А.1 Муу API-ийн шинжилгээ
Дараах 6 дизайны алдааг илрүүлж, засварлалаа:
1. [cite_start]**Нэршил (Naming):** `usr_mgr` нь ойлгомжгүй товчилсон нэр[cite: 21].
2. [cite_start]**Далдлалт (Encapsulation):** `db_conn` public байгаа нь аюултай[cite: 23].
3. [cite_start]**Magic Flags:** `flag: number` нь ямар үйлдэл хийх нь тодорхойгүй[cite: 25].
4. [cite_start]**Төрөл (Typing):** `any` ашигласан нь ойлгомжгүй байдлыг үүсгэж байна[cite: 24, 26].
5. [cite_start]**Алдаа боловсруулалт:** `'ERR_404'` гэж string буцаах нь буруу[cite: 27].
6. [cite_start]**Нэг үүргийн зарчим:** `get_u` нь ID болон Email хоёуланг нь авч байгаа нь буруу[cite: 28].

## А.2 Сангийн дизайн (Library Design)
- **Паттерн:** Factory паттерн ашиглан хэрэглэгчээс бодит хэрэгжүүлэлтүүдийг (LRU, TTL г.м) нуусан.
- **Далдлалт:** `ICache` интерфейсээр дамжуулж харилцахаар зохион байгуулсан.
