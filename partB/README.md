# Part B: REST API Documentation

Энэхүү API нь Part A-д хийсэн Кэш санг ашиглан өгөгдлийг түр хадгалах зориулалттай.

### Endpoint-ууд:
1. **POST /cache** - Өгөгдөл хадгалах
   - Body: `{ "key": "user_1", "value": "Nyam-Od" }`
2. **GET /cache/:key** - Өгөгдөл сэргээх
   - Response: `{ "key": "user_1", "value": "Nyam-Od" }`

### Тест хийсэн байдал:
- Postman ашиглан 5 удаагийн амжилттай хүсэлт илгээж шалгав.
- LRU алгоритм ажиллаж, 10-аас дээш дата ороход хуучныг устгаж байгааг баталгаажуулав.
